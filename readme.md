# تطبيق Todo بسيط

واجهة أمامية بسيطة لتطبيق Todo مع دعم التخزين المحلي (`localStorage`) وتنفيذ عمليات CRUD.

## هيكل المشروع

- `index.html`
- `css/style.css`
- `js/script.js`
- `README.md`

## المميزات

- إضافة مهمة جديدة
- تعديل مهمة موجودة
- حذف مهمة
- تعليم المهمة كمكتملة / غير مكتملة
- حفظ المهام في `localStorage` لتبقى بعد إعادة تحميل الصفحة
- كل مهمة تسجل تاريخ الإنشاء وتاريخ الإكمال عند تغيير الحالة

## طريقة التشغيل

1. افتح `index.html` في المتصفح.
2. أضف المهام في الحقل ثم اضغط "إضافة".
3. استخدم أزرار "تعديل" و"حذف" و"غير مكتملة/مكتملة".
4. اضغط "مسح الكل" لحذف جميع المهام.

## ملاحظات

- تم استخدام `localStorage` لتنفيذ التخزين المحلي.
- تم استخدام `Date` لجمع تاريخ الإنشاء وتاريخ الإكمال.
- تم استخدام `classList` لتحكم في إضافة أو إزالة الكلاسات من العناصر HTML.
- تم استخدام `addEventListener` لربط الأحداث مع العناصر HTML.
